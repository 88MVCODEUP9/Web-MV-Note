# MV Note

Caderno digital para escrever, desenhar e organizar ideias em pastas, com papel
azul, liso ou quadriculado, zoom de precisão e exportação em PNG ou PDF.

Este repositório é o **site do MV Note** (site estático, PWA instalável).

---

## Rodar localmente

```bash
python3 servidor.py
```

Abra <http://localhost:8000>.

Porta ou endereço diferentes:

```bash
MV_NOTE_PORT=8100 python3 servidor.py
MV_HOST=0.0.0.0 python3 servidor.py   # acessar de outro aparelho na rede
```
